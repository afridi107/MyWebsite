# MyWebsite

A modern, mobile-friendly personal website built with plain HTML, CSS and JavaScript — dark theme with blue accents.

- `index.html` — main page (Home, About, Projects, Contact)
- `css/style.css` — styles
- `js/main.js` — mobile menu, active-section highlighting, scroll animations, contact form

## Hosting on GitHub Pages
Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `(root)`.

## Customizing
- Replace `your.email@example.com` in `index.html` and `js/main.js` with your email.
- Edit the project cards in the `#projects` section with your own projects and links.
